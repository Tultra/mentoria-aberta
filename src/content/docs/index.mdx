## Como colaborar

<p class="ma-subtitulo">
  Todo o conteúdo vive em arquivos Markdown no GitHub. Uma correção pequena leva
  menos de dois minutos e não exige instalar nada.
</p>

<ol class="ma-passos">
  <li>
    <strong>Encontre a página</strong>
    <p>
      Use a busca ou a navegação lateral até o trecho que você quer melhorar.
    </p>
  </li>
  <li>
    <strong>Clique em editar</strong>
    <p>
      O link “Editar esta página no GitHub” abre o arquivo já pronto para
      alteração.
    </p>
  </li>
  <li>
    <strong>Abra um pull request</strong>
    <p>Descreva o que mudou e por quê. O modelo de PR guia o preenchimento.</p>
  </li>
  <li>
    <strong>Revisão e publicação</strong>
    <p>Depois do aceite, o site é reconstruído e publicado automaticamente.</p>
  </li>
</ol>
